# pnc

负责当前目标的规划与控制。当前包定义 PlanningInput 及其就绪条件；仿真中的定时完成回执不代表已经实现规划或控制算法。

- 控制输入：brain 当前下发的 mode/WorkItem，不接收完整任务队列。
- 数据输入：map_manager 的一致的业务地图快照，perception 的新鲜定位和观测。
- 输出：当前目标的 status，未来实际控制命令送执行机构。
- 当前输入定位失效、过期、地图 ID 或定位参考不匹配时，应本地停止并报告 BLOCKED，不依赖 brain 往返才能停车。

无历史依赖：不保存跨目标覆盖进度、业务任务检查点、暂停前业务历史或未来任务安排。当前路径、控制器状态、必要的局部规划缓存可以存在，但必须能由当前显式输入重建。

不决定是否回充、恢复哪个任务、下一块区域是什么，或是否永久保存地图对象。这些分别由 brain 和 map_manager 管理。
