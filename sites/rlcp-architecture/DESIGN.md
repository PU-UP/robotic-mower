# RLCP 架构图的界面约定

2026-11-04。参考 Impeccable 的 Operate / Read 模式：面向工程团队的架构理解与评审工具。

## 优先级

画布是主体，模块职责与接口语义按需查看。保留模块点击、接口选择、专题筛选、键盘操作和流程演示；不改变模型中的职责、来源标记和通信方向。

## 三种视图

- 逻辑职责：保留既有布局与交互，方便团队对照原设计。
- 当前三进程：感知定位、决策、规控三个容器，模块按成员归属放置。外部输入与硬件执行在容器之外；TF 仍是 SLAM 公共接口。
- 单进程候选：继续表达候选装配范围，不表示已经决定迁移。

三进程归属在画布内表达，不再在画布上方重复放置三张说明卡片。容器标题与节点阅读顺序一致，避免新增需求持续挤占首屏。

## 连线与详情

- 总览汇总进程间及外部接口，连线端点落在进程边界；不显示子模块之间的线。Business_core 在最上，决策横置，下方感知定位与规控并列，底部为传感器、底板与执行对象。
- 点击模块只展开其相关接口；“返回进程总览”收起详情；演示完整显示所选流程，内部步骤不会因跨进程筛选消失。
- 三进程详情按当前可见接口重新计算正交路径，绕过节点和标题文字。独立端口、36 单位直线进出段与相邻线路避让，减少箭头和转折挤在一起；接口密集时分散到相邻边。
- 标签按实际文字尺寸避让模块、标题和其他标签，优先避开线路；全模块展开截图与碰撞检查纳入验证。
- 规控第一排模块间距为 90 单位，画布高度由 1060 缩减至 990；压缩进程之间及硬件区域留白，保留内部走线空间。
- 总览标签常显，悬停可查看包含的接口；具体接口标签在悬停、键盘聚焦或选中时显示；完整语义始终可从职责面板和接口按钮进入。
- 颜色分别承担明确含义：容器颜色表示进程，具体接口连线颜色表示数据 / 指令 / 反馈，混合类型的汇总线用中性色。不能只靠颜色表达分类。
- 连线路径交叉不表示通信节点；箭头与端点才表示模块连接。

## 视觉与交付

保留浅色工程画布、系统中文字体和低饱和蓝 / 棕 / 绿。主次通过字号、间距与聚焦状态表达，不增加装饰动画。窄屏保持画布可横向滚动，详情移到下方；页面本身不横向溢出。

所有运行资源内嵌到 `dist/index.html`。Impeccable 仅辅助开发，不成为页面依赖。修改源码后重新构建，并验证独立目录中的交付文件。
